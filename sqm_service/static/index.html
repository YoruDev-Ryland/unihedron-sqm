Meter connection

Choose Ethernet or USB serial, then enter an endpoint or pick one from discovery.

Find SQM‑LE meters

Uses Unihedron’s UDP broadcast. Add your LAN subnet as a fallback when Docker or a VLAN swallows the replies.

The container can test USB devices explicitly mapped into it. No privileged access or whole-host device scan is required.

JSON API

Read-only endpoints for readings, statistics, and meter details. Send the generated key in the X-API-Key header.

curl -H "X-API-Key: …" \
  http://localhost:7942/api/latest

The key lives at /data/api_key inside the container.
